# Suhaila Khan — portfolio

A single-page portfolio site. There is no build step: `index.html` holds the page, its styles and its script, and `images/` holds the work samples.

## Put it online with GitHub Pages

1. Create a public repository named `suhailakhan39-svg.github.io`.
2. Upload `index.html`, the `images` folder and this file to the repository (Add file → Upload files, then drag everything in).
3. Commit. The site appears at https://suhailakhan39-svg.github.io within a few minutes.

## Edit it later

- Text: open `index.html` on GitHub, click the pencil icon, change the wording between the tags and commit.
- Images: add the new file to `images/`, then copy an existing `<button class="shot ...">` line in `index.html` and change the file name and the `alt` description.
- Colours and fonts: the first block of `:root { ... }` near the top of `index.html`.
